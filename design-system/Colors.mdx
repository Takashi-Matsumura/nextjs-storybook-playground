# Colors（ブランドカラー）

このアプリで使ってよい色の一覧です。値は **`app/globals.css` の1か所だけ**で管理しています。
見本は CSS 変数を直接表示しているので、OS をダークモードにするとダーク用の色に切り替わります。

## 使い方のルール

- 色は **トークンの名前**（`bg-brand`、`text-fg` など）で指定する
- `bg-pink-600` や `#db2777` のような **色の直書きはしない**
- 新しい色が必要になったら、まず `globals.css` にトークンを追加する

- ✅ よい例：`className="bg-success-bg text-success-fg"`
  → ブランドを変えたいとき、`globals.css` を1行直せば全体が変わる
- ❌ よくない例：`className="bg-green-100 text-green-800 dark:bg-green-900"`
  → 画面ごとに色を探して直す必要がある
